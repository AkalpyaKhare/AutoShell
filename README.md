# AutoShell

AutoShell is a lightweight automation shell written in modern C++. It provides a simple command-line interface for automating repetitive desktop workflows such as file searching, application launching, media playback, and custom task execution.

The project was built to explore systems programming concepts including command parsing, filesystem traversal, process management, workflow automation, and cross-platform development. AutoShell aims to reduce the time spent performing repetitive actions by allowing users to execute complex workflows with a single command.

Key Features:

* Recursive file search
* Command history
* Custom workflows
* Application launching
* Alias support
* Lightweight terminal interface
* Cross-platform architecture

Built with C++17 and the Standard Library.
